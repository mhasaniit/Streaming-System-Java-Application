# Java Streaming System (Audio & Video Playlist Manager)

## Overview
This project is a Java-based streaming system developed for a CS 116 final. It allows users to manage and play audio and video recordings through personalized playlists. The system demonstrates core Object-Oriented Programming (OOP) principles while simulating basic media streaming functionality.

## Features
- User management (basic account handling)
- Create and manage personalized playlists
- Add audio and video files to playlists
- Import media files into the system
- Track playback activity
- Organize and access media content efficiently

## OOP Concepts Applied
- **Encapsulation** – Structured classes to manage user data and media objects
- **Inheritance** – Shared behavior between media types (audio/video)
- **Polymorphism** – Flexible handling of different media formats in playback system

## Technologies Used
- Java
- Eclipse IDE

## Project Structure
- `src/` – Contains all Java source code
- Media classes – Handle audio and video file behavior
- User classes – Manage user accounts and playlists
- Playlist system – Organizes and tracks media selections

## How to Run
1. Import the project into Eclipse IDE  
2. Run the main driver class  
3. Follow console prompts to create users, build playlists, and play media
